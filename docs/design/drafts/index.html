새 project 시작하기

백지 상태에서 why → stack → 구조 → 사양 → task 순으로 좁혀 들어가는 흐름입니다. 이 guide 자체도 이 흐름으로 만들어졌습니다.

mission · spec · tasks
언제 쓰나 — repo 가 비어 있거나 코드가 거의 없을 때. 이미 코드가 있는 repo 라면 11. 기존 repo 진입하기로 가세요.

전체 흐름

  1. ywc-brainstorm선택

    의도가 흐릿할 때 Socratic 대화로 목적·제약·대안을 확정

  2. ywc-mission

    why, success criteria, non-goal, rejected approach 를 docs/mission.md 에 고정

  3. ywc-tech-research선택

    stack 후보를 병렬 비교하고 근거를 docs/research 에 남김

  4. ywc-project-scaffold

    확정된 stack 기준 directory 구조 plan

  5. ywc-spec-writer → ywc-spec-validate

    사양서 작성 후 DONE 이 될 때까지 검증 반복

  6. ywc-task-generator → ywc-confidence-gate

    task 로 분해하고 착수 준비도를 점수화

  7. ywc-task-executor

    dependency 를 보고 순차/병렬 executor 를 자동 선택
