빈 저장소에서 새 프로젝트를 시작할 때, 무엇을 만들지 정하는 일부터 첫 task 실행까지 skill 을 이 순서로 씁니다.

<Aside title="언제 쓰나">
- 아이디어만 있고 저장소에는 아직 code 가 없을 때
- 사양서와 task 목록을 먼저 만들고 그 위에서 구현을 진행하고 싶을 때
</Aside>

<FlowStep skill="ywc-ubiquitous-language" desc="도메인 용어집을 만들어 이후 문서와 code 의 용어를 맞춥니다." optional />

## 건너뛸 수 있는 조건

- **3단계 <SkillLink name="ywc-tech-research" />**: 기술 stack 이 이미 정해져 있으면 건너뜁니다.
- **5단계 <SkillLink name="ywc-ubiquitous-language" />**: 도메인 용어가 적어 용어집이 필요 없으면 건너뜁니다. 나중에 용어가 늘면 그때 만듭니다.
- 이미 code 가 있는 저장소라면 이 흐름 대신 [11 기존 repo 진입하기](/develop-with-llm-guide/flows/onboarding-existing-repo/) 흐름으로 시작합니다.
