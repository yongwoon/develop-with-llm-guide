작업 자체가 아니라 작업 환경을 다듬는 skill 들입니다. 서로 독립이므로 필요할 때 하나씩 씁니다.

<Aside title="언제 쓰나">
- skill 이 매번 묻는 값을 고정하거나, 세션을 다음 세션에 넘길 때
- 세션을 회고하거나 skill·리뷰 학습을 정비할 때
</Aside>

## 세션 운영 흐름

<Flow>
<FlowStep skill="ywc-setup" desc="ywc skill 이 매번 묻는 기본값을 설정 file 에 저장합니다." optional />
<FlowStep skill="ywc-handoff" desc="지금 대화를 새 세션이 이어받을 인수인계 문서로 압축합니다." optional />
<FlowStep skill="ywc-retro" desc="coding 세션을 회고해 작업 환경의 개선안을 냅니다." optional />

<FlowStep skill="ywc-skill-author" desc="ywc skill 을 만들거나 정비하고 규칙 준수를 점검합니다." optional />

</Flow>
