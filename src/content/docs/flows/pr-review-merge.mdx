PR 에 사람이나 bot 의 리뷰가 달리면, 지적을 확인하고 고친 뒤 병합까지 이 순서로 진행합니다.

<Aside title="언제 쓰나">
- 열린 PR 에 리뷰 코멘트가 달려 리뷰 대응이 필요할 때
- 리뷰를 반영한 뒤 병합과 task 완료 처리까지 끝내고 싶을 때
</Aside>

## 리뷰 대응 흐름

<Flow>
<FlowStep skill="ywc-handle-pr-reviews" desc="열린 PR 의 리뷰 코멘트에 대응하고 병합 가능한 상태로 만듭니다." />
<FlowStep skill="ywc-receive-review" desc="받아들이기 전에 지적이 맞는지 하나씩 확인합니다." />

<FlowStep skill="ywc-review-learnings" desc="반복되는 지적이나 false positive 를 저장소의 리뷰 학습으로 남깁니다." optional />
</Flow>

## 건너뛸 수 있는 조건

- **3단계 <SkillLink name="ywc-resolve-conflict" />**: 진행 중인 local merge·rebase 충돌이 없으면 건너뜁니다. 열린 PR 이 base branch 와 충돌하는 경우는 1단계 <SkillLink name="ywc-handle-pr-reviews" /> 가 맡습니다. Claude Code 전용이며 Codex 에서는 위 대체 방법을 씁니다.
- **5단계 <SkillLink name="ywc-review-learnings" />**: 다음 리뷰에도 남길 만한 지적이 없으면 건너뜁니다.
