동작은 그대로 두고 code 구조만 바꾸는 리팩터링은 영향 범위를 먼저 보고, 작은 단위로 바꾼 뒤, 바뀐 경계를 규칙으로 남깁니다.

<Aside title="언제 쓰나">
- module 이 잘게 흩어져 있거나 쓰지 않는 code 가 쌓였을 때
- 리팩터링 결과가 다시 무너지지 않도록 경계 규칙을 두고 싶을 때
</Aside>
