증상만 고치지 않도록 원인을 먼저 찾고, 운영 장애였다면 사후 보고서까지 남깁니다.

<Aside title="언제 쓰나">
- test·build 가 실패하거나 원인을 모르는 bug 가 생겼을 때
- 운영 중 장애가 나서 원인과 재발 방지를 기록해야 할 때
</Aside>
