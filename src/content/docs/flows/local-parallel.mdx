여러 task 를 동시에 진행하려면 task 마다 따로 쓸 작업 공간이 필요합니다. 로컬 환경, worktree, port 분리를 갖춘 뒤 병렬로 실행합니다.

<Aside title="언제 쓰나">
- 서로 독립인 task 가 여러 개라 병렬로 실행해 시간을 줄이고 싶을 때
- worktree 마다 Docker stack 을 띄워도 port 가 충돌하지 않게 하고 싶을 때
</Aside>

## 병렬 작업 흐름

<Flow>
<FlowStep skill="ywc-docker-compose" desc="로컬 Docker Compose 환경을 만들거나 최신화합니다." optional />
<FlowStep skill="ywc-worktrees" desc="작업용 git worktree 를 만들고 점검하고 정리합니다." />
<FlowStep skill="ywc-docker-isolate" desc="worktree 마다 Docker port 를 나눠 stack 충돌을 막습니다." optional />
<FlowStep skill="ywc-parallel-executor" desc="독립인 task 를 worktree 로 나눠 동시에 실행합니다." />
<FlowStep skill="ywc-team-assemble" desc="작업을 전문 역할별 agent 팀에 나눠 맡깁니다." optional />
</Flow>

## 건너뛸 수 있는 조건

- **1단계 <SkillLink name="ywc-docker-compose" />, 3단계 <SkillLink name="ywc-docker-isolate" />**: project 가 Docker 를 쓰지 않으면 둘 다 건너뜁니다.
- **5단계 <SkillLink name="ywc-team-assemble" />**: tasks/ 의 task 가 아니라 역할별로 나눌 작업이 있을 때만 씁니다.
- task 가 서로 의존해 순서대로만 진행할 수 있다면 [13 중·대형 기능](/develop-with-llm-guide/flows/large-feature/) 흐름의 순차 실행을 씁니다.
