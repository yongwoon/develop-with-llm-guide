인프라는 설계 문서를 먼저 만들고, 그 문서를 Terraform 으로 옮긴 뒤 apply 전에 리뷰합니다. 운영에 들어간 뒤에는 개선 후보를 찾아 적용합니다.

<Aside title="언제 쓰나">
- 새 서비스의 cloud 인프라를 설계하고 IaC 로 만들 때
- 운영 중인 인프라의 비용·drift·신뢰성을 개선하고 싶을 때
</Aside>

## 건너뛸 수 있는 조건

- **4단계 <SkillLink name="ywc-infra-optimize" />**: 아직 운영에 들어가지 않았거나 비용·사용량 data 가 없으면 건너뜁니다.
- 이미 Terraform code 가 있는 저장소라면 처음부터 다시 설계하지 않습니다. 기존 code 를 3단계로 리뷰하는 것부터 시작하고, 새 module 이 필요할 때 1–2단계로 돌아옵니다.
