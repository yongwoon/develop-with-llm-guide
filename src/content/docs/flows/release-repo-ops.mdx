릴리스 때는 release PR 설명과 변경 기록을 정리합니다. 의존성 PR 과 issue 정리는 릴리스와 따로 필요할 때 씁니다.

<Aside title="언제 쓰나">
- develop 에서 main 으로 가는 release PR 을 준비할 때
- 쌓인 Dependabot PR 이나 정리되지 않은 issue 를 한 번에 처리할 때
</Aside>

## 릴리스 흐름

<Flow>
<FlowStep skill="ywc-release-pr-list" desc="release PR 에 병합된 PR 목록을 작성자별로 정리합니다." />
<FlowStep skill="ywc-changelog-release-notes" desc="git 이력과 PR 로 CHANGELOG 항목과 release note 를 씁니다." />
<FlowStep skill="ywc-merge-dependabot" desc="쌓인 Dependabot PR 을 종류별로 묶어 일괄 병합합니다." optional />
<FlowStep skill="ywc-issue-triage" tools={['claude-code']} desc="GitHub issue·PR 의 분류와 상태 label 을 정리합니다." optional />
</Flow>

## 건너뛸 수 있는 조건

- **3단계 <SkillLink name="ywc-merge-dependabot" />**: 처리할 Dependabot PR 이 없으면 건너뜁니다.
- **4단계 <SkillLink name="ywc-issue-triage" />**: 정리할 issue 가 없으면 건너뜁니다. Claude Code 전용이며 Codex 에서는 위 대체 방법을 씁니다.
