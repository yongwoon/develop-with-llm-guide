흐름 page 의 실행 예시에서 자주 쓰는 명령을 골랐습니다. `<...>` 부분은 내 상황에 맞게 바꿉니다. option 은 흐름 page 와 같습니다. 두 도구의 명령이 다른 곳은 Codex 열에 따로 적었습니다.

skill 이름을 누르면 skill page 의 option 표로 갈 수 있습니다. 한쪽 도구에만 있는 skill 은 [두 도구의 차이](/develop-with-llm-guide/getting-started/tool-differences/) 를 봅니다.

|---|---|---|---|
| 막연한 아이디어를 정리 (<SkillLink name="ywc-brainstorm" />) | `/ywc-brainstorm <아이디어>` | `$ywc-brainstorm <아이디어>` | [새 project](/develop-with-llm-guide/flows/new-project/) |
