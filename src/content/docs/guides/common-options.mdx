여러 skill 에 같은 이름으로 있는 option 입니다. 아래 section 의 option 은 어느 skill 에서나 뜻이 같습니다. 기본값과 도구별 지원 여부는 skill 마다 다를 수 있으므로, 정확한 값은 각 skill page 의 option 표에서 확인합니다.

## `--dry-run`

**의미**: 실제로 바꾸지 않고, 무엇을 할지만 보여 줍니다. file 을 쓰거나 branch 를 만들지 않습니다.

**언제 쓰나**: 처음 쓰는 skill 이거나 처음 보는 저장소에서 결과를 미리 확인할 때 씁니다. 실행기에서는 실행 순서와 전달 방식을 확인할 때 씁니다.

**주의**: 일부 skill 은 한 도구에만 이 option 이 있습니다. 예를 들어 <SkillLink name="ywc-parallel-executor" /> 는 Codex 에만, <SkillLink name="ywc-project-docs" /> 는 Claude Code 에만 있습니다.

## `--non-interactive`

**의미**: 중간에 질문하지 않고 실행합니다.

**언제 쓰나**: 답할 값을 미리 option 으로 모두 줄 수 있을 때, 또는 다른 skill 이나 script 에서 이어서 실행할 때 씁니다.

**주의**:

- 대부분 Codex 에만 있습니다. Claude Code 에서 쓸 수 있는 skill 은 <SkillLink name="ywc-plan" />, <SkillLink name="ywc-impl-review" />, <SkillLink name="ywc-sequential-executor" />, <SkillLink name="ywc-task-executor" /> 입니다.
- Claude Code 의 <SkillLink name="ywc-impl-review" /> 와 <SkillLink name="ywc-sequential-executor" /> 에서는 특정 질문 하나만 생략합니다. 생략하는 질문은 각 skill page 에 있습니다.
- Codex 의 대부분 skill 은 필요한 값이 빠지면 진행하지 않고 멈춘 상태를 돌려줍니다. <SkillLink name="ywc-plan" /> 처럼 답하지 않은 항목을 기본값으로 채우는 skill 도 있습니다. 함께 줘야 하는 option 이 있는 skill 도 있습니다. 예를 들어 <SkillLink name="ywc-task-generator" /> 는 `--mode` 가 필요합니다.

<OptionUsers name="--non-interactive" />

## `--resume-disposition`

**의미**: 이전 실행 기록이 남아 있을 때 이어서 할지(`resume`), 멈출지(`stop`) 정합니다.

**언제 쓰나**: `--non-interactive` 로 실행하면서, 중단된 이전 실행을 어떻게 다룰지 미리 정할 때 씁니다.

**주의**: Codex 에만 있고 `--non-interactive` 와 함께 씁니다.

<OptionUsers name="--resume-disposition" />

## `--format`

**의미**: 보고서 형식을 `markdown` 과 `html` 중에서 고릅니다. 모든 skill 에서 기본값은 `markdown` 입니다.

**언제 쓰나**: 브라우저로 열어 볼 단독 HTML 보고서가 필요할 때 `--format html` 을 줍니다.

**주의**:

- HTML 보고서가 생기는 디렉터리는 도구마다 다릅니다. Claude Code 는 `claudedocs/`, Codex 는 `codexdocs/` 입니다.
- Claude Code 의 <SkillLink name="ywc-product-review" /> 는 `html` 만 받습니다. Markdown 으로 받으려면 option 을 주지 않습니다.

<OptionUsers name="--format" />

## `--lang` 과 `--pr-lang`

**의미**: `--lang` 은 이번 실행에서 만드는 문서의 언어를 정합니다. `--pr-lang` 은 PR 제목과 설명의 언어를 정합니다.

**언제 쓰나**: 설정해 둔 언어와 다른 언어로 이번만 쓰고 싶을 때 줍니다. 매번 같은 언어를 쓴다면 <SkillLink name="ywc-setup" /> 으로 기본값을 저장해 두는 편이 편합니다.

**주의**:

- <SkillLink name="ywc-setup" /> 의 `--lang` 은 이번 실행이 아니라 모든 skill 의 기본 언어를 저장합니다.
- 받는 값과 기본값은 skill 마다 다릅니다. 여러 skill 이 `ko|ja|en|zh|es` 를 받습니다.
- Codex 의 <SkillLink name="ywc-agentic" /> 에서 `--lang` 은 `--non-interactive` 와 함께만 씁니다.

<OptionUsers name="--lang" />

## `--base-branch`

**의미**: 결과를 병합하거나 PR 을 보낼 base branch 를 정합니다.

**언제 쓰나**: 저장소의 기본 branch 가 아닌 곳에 병합할 때 씁니다.

**주의**:

- 기본값은 skill 마다 다릅니다. 설정값을 쓰는 skill, 저장소에서 추정하는 skill, 현재 branch 를 쓰는 skill 이 있습니다.
- <SkillLink name="ywc-setup" /> 에서는 기본 대상 branch 를 저장합니다.
- <SkillLink name="ywc-agentic" /> 은 branch 이름 외에 `auto` 와 `none` 도 받습니다.
- <SkillLink name="ywc-worktrees" /> 에서는 새 branch 를 만들 출발점이라는 뜻입니다. `--existing-branch` 와 함께 쓸 수 없습니다.

<OptionUsers name="--base-branch" />

## `--tasks-dir`

**의미**: task 디렉터리의 위치를 바꿉니다. 기본값이 있는 skill 은 모두 `tasks/` 입니다.

**언제 쓰나**: task 를 `tasks/` 가 아닌 곳에 둘 때 씁니다. <SkillLink name="ywc-task-generator" /> 에서는 계획을 다시 짤 때 기존 task 와 섞이지 않도록 다른 디렉터리에 만듭니다.

**주의**: task 를 만든 skill 과 실행하는 skill 에 같은 경로를 줍니다.

<OptionUsers name="--tasks-dir" />

## `--spec`

**의미**: 기준이 되는 spec 이나 계획 file 의 경로를 줍니다.

**언제 쓰나**: 구현, 검토, 리뷰를 특정 spec 에 맞춰 할 때 씁니다.

**주의**: 반드시 줘야 하는 skill 과 생략할 수 있는 skill 이 있습니다. <SkillLink name="ywc-code-gen" /> 과 <SkillLink name="ywc-spec-validate" /> 는 반드시 줍니다. <SkillLink name="ywc-impl-review" /> 는 Codex 에서는 반드시 주고, Claude Code 에서는 생략할 수 있습니다. <SkillLink name="ywc-spec-ready" /> 에서는 목표 문장과 함께 쓸 수 없습니다.

<OptionUsers name="--spec" />

## `--manifest`

**의미**: architecture 규약 file(`architecture-invariants.yaml`)의 경로를 줍니다.

**언제 쓰나**: 규약 file 이 저장소 root 가 아닌 곳에 있을 때, 또는 생성할 code 와 task 가 규약을 따르게 할 때 씁니다.

**주의**: 도구마다 이 option 이 있는 skill 이 다릅니다. 규약 file 은 <SkillLink name="ywc-architecture-invariants" /> 로 만듭니다.

<OptionUsers name="--manifest" />

## `--terse`

**의미**: 진행 중 출력이나 완료 보고를 짧게 받습니다.

**언제 쓰나**: 긴 실행에서 요약만 보고 싶을 때 씁니다.

**주의**: 결과물 자체는 바뀌지 않고 보고만 짧아집니다.

<OptionUsers name="--terse" />

## 실행기의 전달·리뷰 option

task 실행기(<SkillLink name="ywc-task-executor" />, <SkillLink name="ywc-sequential-executor" />, <SkillLink name="ywc-parallel-executor" />)에서 결과를 base branch 에 어떻게 넣을지와, 리뷰를 언제 할지 정하는 option 입니다.

| option | 의미 |
|---|---|
| `--local-merge` | PR 없이 base branch 에 직접 병합합니다. 혼자 쓰는 저장소에 맞습니다. |
| `--aggregate-pr` | 결과를 branch 하나에 모아 PR 하나로 전달합니다. |
| `--group-name` | `--aggregate-pr` 로 만들 branch 의 이름을 정합니다. |
| `--draft` | draft PR 만 만들고 병합은 직접 합니다. |
| `--worktree` | 별도 git worktree 에서 실행해 원래 checkout 을 비워 둡니다. |
| `--review` | task 마다 병합 전에 구현 리뷰를 합니다. |
| `--final-review` | 마지막에 전체 결과를 한 번 더 리뷰합니다. |

**언제 쓰나**: 혼자 쓰는 저장소에서 빠르게 끝내려면 `--local-merge --review` 를, 결과를 한 번에 검토받으려면 `--aggregate-pr` 를 씁니다.

**주의**:

- 전달 방식(`--local-merge`, `--aggregate-pr`, `--draft` 등)은 하나만 고르며 함께 쓸 수 없습니다. <SkillLink name="ywc-parallel-executor" /> 는 하나도 주지 않으면 실행 전에 물어봅니다.
- Codex 의 <SkillLink name="ywc-task-executor" /> 는 이 flag 대신 `--delivery <방식>` 으로 고릅니다. 예를 들어 `--local-merge` 는 `--delivery local-merge` 입니다.
- `--group-name` 은 `--aggregate-pr` 와 함께만 씁니다.
- <SkillLink name="ywc-incident-postmortem" /> 의 `--draft` 는 전달 방식과 관계없습니다. 질문에 답하며 보고서를 쓰는 기본 동작을 뜻합니다.
- <SkillLink name="ywc-handle-pr-reviews" /> 의 `--worktree` 는 PR branch 를 별도 worktree 에서 다룹니다. fork 에서 온 PR 은 지원하지 않습니다.
- <SkillLink name="ywc-code-gen" /> 의 `--review` 는 생성이 끝난 뒤 구현 리뷰를 한 번 이어서 실행합니다.

## skill 마다 뜻이 다른 option

아래 option 은 이름은 같지만 skill 마다 받는 값과 뜻이 다릅니다. 쓰기 전에 해당 skill page 의 option 표를 확인합니다.

| option | 예 | 쓰는 skill |
|---|---|---|
| `--mode` | 동작을 고릅니다. <SkillLink name="ywc-task-generator" /> 는 task 크기(`human\|llm`), <SkillLink name="ywc-finish-branch" /> 는 전달 방식, <SkillLink name="ywc-mission" /> 은 읽기·추가·정리입니다. | <OptionUsers name="--mode" /> |
| `--scope` | 대부분 점검 범위 경로입니다. <SkillLink name="ywc-setup" /> 에서는 저장 위치(`project\|user`)입니다. | <OptionUsers name="--scope" /> |
| `--output` | 결과 file 의 경로입니다. 기본 경로는 skill 마다 다릅니다. | <OptionUsers name="--output" /> |
| `--target` | 점검 대상(`code\|docs\|both`), 화면 경로, 적용 경로 등 skill 마다 다릅니다. | <OptionUsers name="--target" /> |
| `--depth` | 리뷰의 강도, 또는 보고서 분량입니다. | <OptionUsers name="--depth" /> |
| `--limit` | 가져올 issue 수, 또는 볼 PR 수의 상한입니다. | <OptionUsers name="--limit" /> |
| `--max-iterations` | 되풀이할 최대 횟수입니다. 기본값이 skill 과 도구마다 다릅니다. | <OptionUsers name="--max-iterations" /> |
| `--task-name` | task 이름입니다. 무엇에 쓰는지는 skill 마다 다릅니다. | <OptionUsers name="--task-name" /> |

<Aside>
skill 이름을 누르면 그 skill page 로 이동합니다. option 표는 page 의 Options section 에 있습니다.
</Aside>
