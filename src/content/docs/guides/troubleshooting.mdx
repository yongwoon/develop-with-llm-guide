## 한눈에 보기

| 증상 | 확인할 것 | 해결 |
|---|---|---|
| 설치했는데 skill 이 안 보임 | 도구를 다시 시작했는지, 설치 위치 | 도구 재시작. 아래 [설치 후 skill 이 보이지 않음](#설치-후-skill-이-보이지-않음) |
| Codex 에서 `$ywc-...` 를 찾지 못함 | `~/.codex/skills/` 에 있는지, Claude Code 전용 skill 인지 | 아래 [Codex 에서 호출이 안 됨](#codex-에서-호출이-안-됨) |
| PR·CI·병합 skill 이 실패함 | `gh auth status` | `gh auth login` |
| executor 가 중간에 끊김 | 같은 명령을 다시 실행 | 이어서 할지 묻는 질문에 답합니다 |
| executor 가 시작하지 않음 | working tree, 현재 branch | commit·stash 후 base branch 에서 실행 |
| option 이 함께 쓸 수 없다고 멈춤 | 전달 방식 option 을 둘 이상 줬는지 | 하나만 남깁니다 |
| 설정한 언어·base branch 가 적용되지 않음 | option, project file, 사용자 file 의 순서 | [설정](/develop-with-llm-guide/guides/configuration/) 의 우선순위 확인 |
| 이 사이트 검색에 결과가 없음 | 실패 안내가 떴는지 | 새로고침, 또는 Skill 색인 이용 |

## 설치 후 skill 이 보이지 않음

1. Claude Code 와 Codex 를 다시 시작합니다. 설치한 뒤에는 재시작해야 새 skill 과 agent 가 보입니다.
2. 그래도 없으면 설치 위치에 skill 디렉터리가 있는지 봅니다.

| 대상 | 기본 위치 | 위치를 바꾸는 환경 변수 |
|---|---|---|
| Claude Code skill | `~/.claude/skills/` | `CLAUDE_SKILLS_DIR` |
| Claude Code agent | `~/.claude/agents/` | `CLAUDE_AGENTS_DIR` |
| Codex skill | `~/.codex/skills/` | `CODEX_HOME` |
| Codex agent | `~/.codex/agents/` | `CODEX_HOME` |

3. 환경 변수로 위치를 바꿨다면 도구도 같은 위치를 보는지 확인합니다.
4. `--claude-only`·`--codex-only` 등으로 일부만 설치했다면 필요한 쪽을 다시 설치합니다. 자세한 option 은 [설치](/develop-with-llm-guide/getting-started/install/) 를 봅니다.

## Codex 에서 호출이 안 됨

- Codex 에서는 `/` 가 아니라 `$` 로 부릅니다. 예: `$ywc-plan`.
- <SkillLink name="ywc-adr" />, <SkillLink name="ywc-issue-triage" />, <SkillLink name="ywc-manual-wizard" />, <SkillLink name="ywc-resolve-conflict" /> 는 Claude Code 전용이라 Codex 에는 없습니다. 각 page 에 Codex 에서 쓸 대체 방법이 있습니다.
- 그 밖의 skill 이 없으면 `~/.codex/skills/` (또는 `CODEX_HOME` 아래 `skills/`) 에 해당 디렉터리가 있는지 보고, Codex 를 다시 시작합니다.

자세한 차이는 [두 도구의 차이](/develop-with-llm-guide/getting-started/tool-differences/) 를 봅니다.

## gh 인증이 안 되어 PR skill 이 실패함

PR 생성, CI 대기, 병합을 하는 skill 은 GitHub CLI (`gh`) 가 인증되어 있어야 합니다. 인증이 안 되어 있으면 executor 는 시작하지 않습니다. <SkillLink name="ywc-parallel-executor" /> 는 PR 을 만드는 전달 방식일 때만 확인합니다.

```bash
gh auth status   # 상태 확인
gh auth login    # 인증
```

## executor 실행이 중간에 끊김

<SkillLink name="ywc-sequential-executor" /> 와 <SkillLink name="ywc-parallel-executor" /> 는 진행 상황을 기록해 둡니다. 끊긴 뒤 같은 명령을 다시 실행하면 이어서 할지 묻습니다.

| 상황 | 묻는 내용 | 고르면 |
|---|---|---|
| 같은 명령, 또는 범위 없이 다시 실행 | 이어서 할지 | 예: 끝난 task 는 건너뛰고 진행 중이던 task 부터 이어 갑니다. 아니오: 기록을 지우고 새로 시작합니다. |
| 기록과 다른 범위를 지정해 실행 | 남은 실행을 이을지, 버리고 새 범위를 시작할지 | 자동으로 이어 가지 않습니다. 둘 중 하나를 직접 고릅니다. |
| 다른 executor 의 기록이 남아 있음 | — | 이어 갈 수 없습니다. 원래 쓰던 executor 로 다시 실행합니다. |

Codex 에서 `--non-interactive` 로 실행할 때 기록이 남아 있으면 `--resume-disposition resume` (이어서) 또는 `stop` (멈춤) 을 함께 줘야 합니다.

## executor 가 시작하자마자 멈춤

| 증상 | 해결 |
|---|---|
| working tree 가 깨끗하지 않다고 멈춤 | 변경을 commit 하거나 stash 한 뒤 다시 실행합니다. |
| base branch 가 아니라고 경고함 | base branch 로 checkout 한 뒤 실행합니다. <SkillLink name="ywc-sequential-executor" /> 는 feature branch 에서 계속할지 묻고, `--base-branch` 와 현재 branch 가 같으면 묻지 않습니다. <SkillLink name="ywc-parallel-executor" /> 는 base branch 위에서 실행해야 합니다. |
| task 디렉터리가 없다고 멈춤 | `tasks/` 에 task 디렉터리와 `dependency-graph.md` 가 있는지 봅니다. 다른 곳이면 `--tasks-dir` 를 줍니다. |
| 외부 URL 을 읽을지 물음 | project 마다 한 번만 묻습니다. 값과 저장 위치는 [설정](/develop-with-llm-guide/guides/configuration/) 의 외부 URL 정책을 봅니다. |

## option 이 함께 쓸 수 없다고 멈춤

executor 의 전달 방식 option `--local-merge`, `--draft`, `--skip-ci-wait`, `--aggregate-pr` 은 하나만 고릅니다. 둘 이상 주면 branch 를 만들기 전에 멈추고 어느 방식인지 묻습니다. <SkillLink name="ywc-sequential-executor" /> 의 `--worktree`, `--review`, `--non-interactive` 는 전달 방식과 함께 쓸 수 있습니다.

| option | 함께 써야 하는 것 | 없을 때 |
|---|---|---|
| `--group-name` | `--aggregate-pr` | 쓸 수 없습니다 |
| `--skip-baseline` (Claude Code) | `--worktree` | 경고하고 무시합니다 |
| `--run-tests-locally` | `--local-merge` | 효과가 없습니다 |

<SkillLink name="ywc-parallel-executor" /> 도 전달 방식 option 은 하나만 고릅니다. 하나도 주지 않으면 실행 전에 묻습니다.

## 언어·base branch 기본값이 적용되지 않음

- 실행할 때 준 option 이 설정 file 보다 우선합니다.
- project 설정 file 이 사용자 설정 file 보다 우선합니다. project file 의 `lang` 이 사용자 file 의 `lang.pr` 보다 강합니다.
- file 은 저장소 root 에 있어야 합니다. Claude Code 는 `.ywc-config.json`, Codex 는 `.codex/ywc.json` 입니다.
- 값은 정규 코드 (`ko` 등) 로, `lang.pr` 같은 key 는 점이 들어간 이름 그대로 적어야 합니다. 잘못된 값은 건너뜁니다.

자세한 우선순위와 key 는 [설정](/develop-with-llm-guide/guides/configuration/) 을 봅니다.

## 이 사이트 검색에 아무것도 나오지 않음

| 보이는 안내 | 뜻 | 해결 |
|---|---|---|
| 검색을 불러오지 못했습니다. 새로고침하거나 Skill 색인에서 찾아 주세요. | 검색 index 를 받지 못했습니다. tab 을 연 사이에 사이트가 다시 배포된 경우도 포함합니다. | page 를 새로고침합니다. 그래도 안 되면 [Skill 색인](/develop-with-llm-guide/skills/) 에서 찾습니다. |
| "(검색어) 검색 결과가 없습니다" | 검색은 됐지만 맞는 page 가 없습니다. | skill 이름 (예: `ywc-plan`) 이나 다른 낱말로 다시 찾습니다. |
| 검색 단추 대신 Skill 색인 link 만 보임 | 브라우저에서 JavaScript 가 꺼져 있습니다. | JavaScript 를 켜거나 Skill 색인을 씁니다. |
