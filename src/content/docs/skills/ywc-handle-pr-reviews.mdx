## 사용 case

### bot 리뷰가 달린 PR 정리

PR 15 에 CodeRabbit 코멘트가 여러 개 달렸고 CI 도 하나 실패했습니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-handle-pr-reviews 15
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-handle-pr-reviews 15
```
</TabItem>
</Tabs>

**결과물**: 코멘트마다 지적이 맞는지 확인하고, 맞는 것은 고쳐서 commit 합니다. 각 thread 에 답변을 남기고 CI 실패도 고칩니다. 끝나면 PR 의 병합 가능 여부를 보고합니다.

### 다른 작업 중에 PR 만 따로

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-handle-pr-reviews 15 --worktree
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-handle-pr-reviews 15 --worktree
```
</TabItem>
</Tabs>

**결과물**: 별도 worktree 에서 PR 15 의 branch 를 꺼내 같은 대응을 합니다.
