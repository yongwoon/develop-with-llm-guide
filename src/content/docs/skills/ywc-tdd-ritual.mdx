## 사용 case

### bug 를 test 로 먼저 재현

Skill 색인에서 분류 filter 를 바꾸면 개수 표시가 갱신되지 않습니다.

</TabItem>
<TabItem label="Codex">

**결과물**: 먼저 bug 를 재현하는 test 가 생기고, 실패하는 것을 확인합니다. 그다음 test 를 통과시키는 최소한의 수정이 들어가고, 마지막에 code 를 정리합니다.
