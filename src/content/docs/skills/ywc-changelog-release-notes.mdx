  - name: --changelog

  - name: --release
    format: flag

    format: flag
    when: CHANGELOG 항목과 release note 를 함께 만듭니다.

  - name: --from
    format: "<tag>"
    default: 마지막 tag

    when: 변경을 모을 끝 지점을 정합니다.
    tools: [claude-code, codex]
  - name: --version
    format: "<v>"

  - name: --pr-list
    format: "<file>"

    tools: [claude-code, codex]
  - name: --dry-run
    format: flag
    when: 결과만 출력하고 CHANGELOG.md 는 고치지 않습니다.
    tools: [claude-code, codex]

## 사용 case

### 새 버전의 CHANGELOG 와 release note

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-changelog-release-notes --both --from v1.2.0 --version 1.3.0
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-changelog-release-notes --both --from v1.2.0 --version 1.3.0
```
</TabItem>
</Tabs>

**결과물**: v1.2.0 이후 변경으로 `CHANGELOG.md` 에 1.3.0 항목이 추가됩니다. 사용자용 release note 도 함께 나옵니다.
