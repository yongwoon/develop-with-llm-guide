## 사용 case

### Phase 하나를 PR 없이 끝까지

혼자 쓰는 저장소입니다. Phase 3 의 task 를 차례로 구현하고 바로 병합합니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-sequential-executor 000003-010..000003-050 --local-merge --review
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-sequential-executor 000003-010..000003-050 --local-merge --review
```
</TabItem>
</Tabs>

**결과물**: task 마다 branch 가 생기고, 구현·검증·리뷰 뒤 base branch 에 병합됩니다. 끝난 task 디렉터리는 `tasks/completed/` 로 옮겨집니다. 마지막에 완료 보고와 진행 중 내린 판단 목록이 나옵니다.

### 다음 task 하나만 PR 로

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-sequential-executor
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-sequential-executor
```
</TabItem>
</Tabs>

**결과물**: 의존 관계가 풀린 다음 task 하나를 실행합니다. PR 을 만들고 CI 와 자동 리뷰를 기다린 뒤 병합합니다.

## 쓰지 말아야 할 때

- 서로 독립인 task 를 동시에 돌릴 때 → `ywc-parallel-executor`
- 순차·병렬을 정하지 않고 맡길 때 → `ywc-task-executor`
- task 디렉터리 없이 spec 에서 바로 구현할 때 → `ywc-code-gen`
- 목표 문장 하나로 계획부터 맡길 때 → `ywc-agentic`
