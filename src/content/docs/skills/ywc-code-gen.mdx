## 사용 case

### spec 이 있는 기능을 층별로 한 번에

option 표 자동 생성 기능의 spec 이 있습니다. task 로 나누지 않고 바로 code 를 만듭니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-code-gen --spec docs/ywc-plans/20261028-option-table.md --feature "frontmatter 에서 option 표를 그린다" --tdd --review
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-code-gen --spec docs/ywc-plans/20261028-option-table.md --feature "frontmatter 에서 option 표를 그린다" --tdd --review
```
</TabItem>
</Tabs>

**결과물**: 필요한 층의 code 와 test 가 생깁니다. test 를 먼저 쓰는 단계마다 commit 이 남고, 마지막에 구현 리뷰 결과가 나옵니다.

## 쓰지 말아야 할 때

- 이미 task 디렉터리로 나눠 둔 작업일 때 → `ywc-sequential-executor` 또는 `ywc-parallel-executor`
- test 를 먼저 쓰는 것만 필요할 때 → `ywc-tdd-ritual`
- 아직 spec 이 없을 때 → `ywc-plan`
- file 하나 수정, refactor, debug 일 때 → skill 없이 직접 요청
