## 사용 case

### Phase 하나를 알맞은 방식으로

Phase 4 의 task 들이 서로 독립인지 따지지 않고 맡깁니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-task-executor 000004-010..000004-030 --local-merge --review
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-task-executor 000004-010..000004-030 --delivery local-merge --review
```
</TabItem>
</Tabs>

**결과물**: 의존 관계에 따라 순차 또는 병렬 실행이 선택되고, 선택된 executor 의 결과가 그대로 나옵니다. 어떤 방식을 골랐는지도 보고에 나옵니다.

### 실행 전에 선택만 확인

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-task-executor 000004-010..000004-030 --dry-run
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-task-executor 000004-010..000004-030 --dry-run
```
</TabItem>
</Tabs>

**결과물**: 순차와 병렬 중 무엇을 고를지, 대상 task 와 전달 방식이 무엇인지만 보여 줍니다.

## 쓰지 말아야 할 때

- 순차 실행을 직접 고를 때 → `ywc-sequential-executor`
- 병렬 실행을 직접 고를 때 → `ywc-parallel-executor`
- task 디렉터리가 아직 없을 때 → `ywc-task-generator` 또는 `ywc-code-gen`
- 목표 문장 하나로 계획부터 맡길 때 → `ywc-agentic`
