kind: skill

summary: 완성된 spec 을 구현 task 디렉터리와 의존 그래프로 나눕니다.
next: [ywc-confidence-gate]
outputs: ["tasks/<task>/", tasks/dependency-graph.md]
argsNote: 분해할 spec 은 요청 문장에 경로로 적습니다.
options:
  - name: --lang
    format: "ko|ja|en|zh|es"
    default: task 문서 언어 설정값
    when: task 문서를 쓸 언어를 이번만 바꿉니다.
    tools: [claude-code, codex]
  - name: --mode
    format: "human|llm"
    default: 설정값. 없으면 물어봄
    when: task 크기를 정합니다. human 은 사람이 손으로 할 단위, llm 은 LLM 이 한 번에 처리할 단위입니다.
    tools: [claude-code, codex]
  - name: --tasks-dir
    format: "<path>"
    default: tasks/
    when: 계획을 다시 짤 때 다른 디렉터리에 만듭니다. 기존 task 와 섞이지 않습니다.
    tools: [claude-code, codex]
  - name: --approve-preview
    format: flag
    when: 질문 없이 실행할 때, 분해 미리보기를 이미 확인했다는 표시로 줍니다.
    tools: [claude-code, codex]
    note: Codex 에서는 --preview-path, --preview-digest 와 함께 씁니다. --preview-only 와는 함께 쓸 수 없습니다.
  - name: --manifest
    format: "<repository-relative-path>"
    when: architecture 규약 file 이 있으면 그 경로를 줍니다. 규약을 task 에 반영합니다.
    tools: [codex]
  - name: --initials
    format: "<value>"
    default: 설정값
    when: 여러 사람이 같은 저장소에서 task 를 만들 때 씁니다. 2~4자 소문자·숫자 이니셜을 붙여 번호가 겹치지 않게 합니다.
    tools: [codex]
  - name: --non-interactive
    format: flag
    when: 질문 없이 실행할 때 씁니다. 필요한 값이 빠지면 아무것도 쓰지 않고 되묻습니다.
    tools: [codex]
    note: --mode 를 함께 줘야 합니다. 언어 설정값이 없으면 --lang 도 필요합니다.
  - name: --preview-only
    format: flag
    when: task 를 만들지 않고 분해 미리보기만 file 로 남깁니다. 먼저 확인할 때 씁니다.
    tools: [codex]
    note: --approve-preview 와 함께 쓸 수 없습니다.
  - name: --preview-path
    format: "<path>"
    when: 저장해 둔 미리보기로 task 를 만들 때 반드시 그 file 경로를 줍니다. 경로는 docs/ywc-plans/ 아래입니다.
    tools: [codex]
  - name: --preview-digest
    format: "<sha256>"
    when: 미리보기를 만들 때 받은 digest 를 줍니다. 확인한 미리보기 그대로 task 를 만듭니다.
    tools: [codex]

## 사용 case

### 통과한 spec 을 task 로 나누기

<SkillLink name="ywc-spec-ready" /> 를 통과한 spec 이 있습니다. LLM 실행 단위의 task 로 나눕니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-task-generator docs/ywc-plans/20261028-option-table.md --mode llm --lang ko
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-task-generator docs/ywc-plans/20261028-option-table.md --mode llm --lang ko
```
</TabItem>
</Tabs>

**결과물**: 먼저 분해 미리보기를 보여 줍니다. 이어서 `tasks/<task>/` 마다 README, 구현 체크리스트, 수동 테스트 계획을 만듭니다. 실행 순서는 `tasks/dependency-graph.md` 에 정리합니다. task 실행은 하지 않습니다.
