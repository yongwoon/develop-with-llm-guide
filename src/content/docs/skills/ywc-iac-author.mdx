## 사용 case

### 설계 문서에서 compute module 만

`docs/infrastructure/` 의 설계에서 staging 환경용 compute module 만 만듭니다. Codex 에는 설계 경로 option 이 없어 문장으로 줍니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-iac-author --module compute
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-iac-author docs/infrastructure 설계의 compute module 을 GCP staging 환경용으로 작성한다
```
</TabItem>
</Tabs>

**결과물**: compute module 의 Terraform code 가 생기고 `terraform plan` 확인 결과가 나옵니다. plan 을 실행하지 못한 경우에는 실행하지 못했다고 표시합니다. 어떤 자원이 생기거나 바뀌는지 영향 요약도 함께 나옵니다.
