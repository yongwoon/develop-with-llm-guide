## 사용 case

### 이 저장소의 언어와 base branch 고정

이 skill 은 사용자가 직접 호출해야 실행됩니다. Codex 에서는 이 제한이 권고 수준입니다. 모든 skill 의 언어는 한국어로, base branch 는 develop 으로 고정합니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-setup --scope project --lang ko --base-branch develop
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-setup --scope project --lang ko --base-branch develop
```
</TabItem>
</Tabs>

**결과물**: 저장소 안의 설정 file 에 값이 저장됩니다. Claude Code 는 저장소 root 의 `.ywc-config.json`, Codex 는 `.codex/ywc.json` 에 씁니다. 이후 ywc skill 은 언어와 base branch 를 묻지 않습니다.
