## 사용 case

### component 디렉터리의 개선 후보 보기

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-improve-architecture --scope src/components --dry-run
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-improve-architecture --scope src/components --dry-run
```
</TabItem>
</Tabs>

**결과물**: 합칠 수 있는 module 묶음이 위험 등급과 함께 목록으로 나옵니다. code 는 바꾸지 않습니다.

### 안전한 것만 재구성

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-improve-architecture --scope src/components --tier safe
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-improve-architecture --scope src/components --tier safe
```
</TabItem>
</Tabs>

**결과물**: safe 등급 후보를 하나씩 재구성합니다. 단위마다 동작이 같은지 확인하고 따로 commit 합니다.
