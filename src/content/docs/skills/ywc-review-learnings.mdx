## 사용 case

### 잘못된 지적을 다시 받지 않게

리뷰가 test fixture 의 하드코딩 값을 계속 지적합니다. 이 project 에서는 문제가 아니라고 남깁니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-review-learnings tests/fixtures 의 하드코딩 값 지적은 false positive 다. fixture 는 고정값이 맞다
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-review-learnings tests/fixtures 의 하드코딩 값 지적은 false positive 다. fixture 는 고정값이 맞다
```
</TabItem>
</Tabs>

**결과물**: `docs/review-learnings.md` 에 추가할 항목을 먼저 보여 줍니다. 확인하면 FALSE-POSITIVE 항목으로 기록됩니다. 다음 <SkillLink name="ywc-impl-review" /> 는 이 지적을 내지 않습니다.

### PR 의 bot 코멘트에서 선호 추출

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-review-learnings --mode update --source pr --pr 15
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-review-learnings --mode update --source pr --pr 15
```
</TabItem>
</Tabs>

**결과물**: PR 15 의 bot 리뷰 코멘트 중 계속 지킬 만한 것을 골라 선호 후보로 보여 줍니다.
