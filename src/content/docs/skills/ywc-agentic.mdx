## 사용 case

### 목표만 주고 구현까지

skill 색인에 분류 filter 를 넣고 싶습니다. 계획부터 구현과 PR 까지 맡깁니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-agentic skill 색인에 분류 filter 를 추가한다 --mode llm --finish pr
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-agentic skill 색인에 분류 filter 를 추가한다 --mode llm --finish pr
```
</TabItem>
</Tabs>

**결과물**: 계획 문서와 task 가 생기고 구현이 진행됩니다. 진행 기록은 `tasks/agentic-log.md` 에 남습니다. 끝나면 base branch 를 trunk 로 보내는 PR 이 하나 생깁니다.

## 쓰지 말아야 할 때

- 단계마다 직접 확인하며 진행할 때 → `ywc-plan` 부터 하나씩
- 이미 나눠 둔 task 를 실행할 때 → `ywc-sequential-executor` 또는 `ywc-parallel-executor`
- skill 하나만 쓰면 될 때 → 그 skill 을 직접 호출
