## 사용 case

### bot 의 지적을 바로 받아들이기 전에

CodeRabbit 이 "이 함수는 null 을 처리하지 않습니다"라고 지적했습니다. 실제로 그런지 확인하고 대응합니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-receive-review CodeRabbit: src/components/SkillIndex.astro 의 filter 함수가 null 을 처리하지 않는다
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-receive-review CodeRabbit: src/components/SkillIndex.astro 의 filter 함수가 null 을 처리하지 않는다
```
</TabItem>
</Tabs>

**결과물**: 지적마다 code 를 확인한 근거와 함께 맞음·틀림·불분명으로 판정합니다. 맞는 지적만 고치고, 틀린 지적에는 근거를 담은 답변안을 냅니다.
