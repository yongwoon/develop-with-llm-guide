## 사용 case

### 보안 관련 PR 만 먼저

Dependabot 보안 경고 PR 만 먼저 병합합니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-merge-dependabot security
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-merge-dependabot security
```
</TabItem>
</Tabs>

**결과물**: 보안 관련 Dependabot PR 이 의존성 종류별로 묶여 병합됩니다. major 버전 올림은 병합하지 않고 따로 보고합니다.

- Dependabot 이 아닌 PR 을 병합할 때 → `ywc-finish-branch`
- docker image 를 직접 최신화할 때 → `ywc-docker-compose`
