## 사용 case

### 먼저 후보만 보기

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-refactor-clean --scope src/ --dry-run
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-refactor-clean --scope src/ --dry-run
```
</TabItem>
</Tabs>

**결과물**: 지울 후보가 safe, caution, danger 등급으로 나뉘어 나옵니다. file 은 바꾸지 않습니다.

### 안전한 것만 지우기

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-refactor-clean --scope src/ --tier safe
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-refactor-clean --scope src/ --tier safe
```
</TabItem>
</Tabs>

**결과물**: safe 등급만 하나씩 지웁니다. 항목마다 test 를 확인하고 commit 을 따로 남깁니다.
