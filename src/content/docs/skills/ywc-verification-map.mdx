## 사용 case

### 이 사이트의 검증 방법 정하기

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-verification-map --init
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-verification-map --init
```
</TabItem>
</Tabs>

**결과물**: 주 사용자 화면(이 사이트라면 web)을 찾고, 띄우는 방법과 확인할 기능 3~5개를 담은 검증 계약을 제안합니다. 승인하면 project 안에 file 로 남습니다.

### 계약대로 동작하는지 감사

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-verification-map --audit
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-verification-map --audit
```
</TabItem>
</Tabs>

**결과물**: 계약에 적힌 기능을 실제로 띄워 확인한 결과와 증거가 나옵니다.
