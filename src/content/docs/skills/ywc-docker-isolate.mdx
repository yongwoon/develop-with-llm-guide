## 사용 case

### worktree 두 개가 같은 port 를 쓸 때

병렬 실행 중 두 worktree 가 모두 DB port 5432 를 쓰려고 해서 "port is already allocated" 가 납니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-docker-isolate setup --task-name 000004-020-ui-flow-pages-18-25 --worktree-path .worktrees/000004-020-ui-flow-pages-18-25
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-docker-isolate --mode setup --isolation-key 000004-020-ui-flow-pages-18-25 --execution-root .worktrees/000004-020-ui-flow-pages-18-25
```
</TabItem>
</Tabs>

**결과물**: 그 worktree 전용 port 묶음과 compose project 이름이 정해집니다. 값은 worktree 의 `.env` 와 port 기록 file 에 쓰입니다. 다른 worktree 의 stack 과 충돌하지 않습니다.

### 끝난 뒤 남은 stack 정리

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-docker-isolate audit --expect 000004-010-ui-flow-pages-10-17,000004-020-ui-flow-pages-18-25 --prune
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-docker-isolate --mode audit --expect-keys 000004-010-ui-flow-pages-10-17,000004-020-ui-flow-pages-18-25 --prune
```
</TabItem>
</Tabs>

**결과물**: 해당 task 의 stack 이 남아 있으면 보고하고 정리합니다.
