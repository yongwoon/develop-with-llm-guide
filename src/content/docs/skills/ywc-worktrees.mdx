## 사용 case

### 남은 worktree 점검

병렬 실행이 중간에 끊겼습니다. 지금 남아 있어야 할 worktree 와 실제 상태를 비교합니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-worktrees --mode audit --expect 000004-010,000004-020
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-worktrees --mode audit --expect 000004-010,000004-020
```
</TabItem>
</Tabs>

**결과물**: 남은 worktree 목록과 기대한 목록의 차이가 나옵니다. 차이가 있으면 점검 결과가 실패로 나옵니다.

### 끝난 task 의 worktree 정리

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-worktrees --mode prune --task-name 000004-010-ui-flow-pages-10-17
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-worktrees --mode prune --task-name 000004-010-ui-flow-pages-10-17
```
</TabItem>
</Tabs>

**결과물**: 해당 worktree 와 local branch 가 지워집니다. 변경이 남아 있으면 지우지 않고 멈춥니다.

## 쓰지 말아야 할 때

- branch 만 만들거나 지울 때 → git 명령으로 직접
- 병합과 완료 처리까지 할 때 → `ywc-finish-branch`
- Docker port 를 분리할 때 → `ywc-docker-isolate`
