## 사용 case

### task 를 만들기 전 spec 점검

`docs/specification/` 을 다 썼습니다. task 로 나누기 전에 한 번 검토합니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-spec-validate --spec docs/specification/02-features.md
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-spec-validate --spec docs/specification/02-features.md
```
</TabItem>
</Tabs>

**결과물**: 심각도별 지적 목록이 대화에 나옵니다. task 분해로 넘어가도 되는지에 대한 판정도 함께 나옵니다. spec file 은 고치지 않습니다.

### 만든 task 와 spec 의 어긋남 확인

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-spec-validate --spec docs/specification/02-features.md --tasks tasks/
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-spec-validate --spec docs/specification/02-features.md --tasks tasks/
```
</TabItem>
</Tabs>

**결과물**: 위 보고서에 두 가지가 더해집니다. 어느 task 도 맡지 않은 요구사항과, spec 에 근거가 없는 task 입니다.
