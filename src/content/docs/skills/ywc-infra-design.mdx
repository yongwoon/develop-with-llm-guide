## 사용 case

### 작은 API 서비스의 GCP 인프라

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-infra-design --provider gcp
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-infra-design GCP 에 작은 API 서비스와 PostgreSQL 을 둔다. region 은 asia-northeast1
```
</TabItem>
</Tabs>

**결과물**: 요구사항 질문에 답하면 서비스 구성과 그 이유가 정리됩니다. 결과는 `docs/infrastructure/` 의 설계 문서 묶음으로 남고, `ywc-iac-author` 의 입력이 됩니다.
