## 사용 case

### monorepo 의 web app 만 파악

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-onboard-repo --scope apps/web/
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-onboard-repo --scope apps/web/
```
</TabItem>
</Tabs>

**결과물**: `apps/web/` 의 구조, 실행 방법, 규칙을 정리한 onboarding guide 가 나옵니다. 감지한 규칙으로 시작용 지침 file 도 저장소 root 에 씁니다.
