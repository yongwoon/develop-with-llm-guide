## 사용 case

### OAuth app 등록 절차를 wizard 로

Google Cloud console 에서 OAuth client 를 직접 만들어야 합니다. 단계와 확인을 안내하는 script 를 만듭니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-manual-wizard Google OAuth client 를 등록하고 client ID 를 .env 에 넣는 절차 --output ./register-oauth-client.sh
```
</TabItem>
<TabItem label="Codex">
Codex 에는 이 skill 이 없습니다. 절차를 문서로 정리하거나, 같은 요청을 Claude Code 에서 실행합니다.
</TabItem>
</Tabs>

**결과물**: `./register-oauth-client.sh` 가 생깁니다. 실행하면 단계마다 할 일을 보여 주고, 사람의 확인과 입력을 받으며 진행합니다.
