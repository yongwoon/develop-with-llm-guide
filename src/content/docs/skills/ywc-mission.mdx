## 사용 case

### 기각한 접근을 기록

private 저장소에서 content 를 가져오는 sync script 는 쓰지 않기로 했다. 다음 세션에서 같은 제안이 나오지 않게 이유와 함께 남긴다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-mission private 저장소 content sync script 는 기각. 유출 경로가 되기 때문
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-mission private 저장소 content sync script 는 기각. 유출 경로가 되기 때문
```
</TabItem>
</Tabs>

**결과물**: `docs/mission.md` 의 기각한 접근 표에 ID 가 붙은 항목이 추가되고 변경 이력이 남는다.

### 오래된 항목 정리

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-mission --mode curate --dry-run
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-mission --mode curate --dry-run
```
</TabItem>
</Tabs>

**결과물**: 정리 대상과 바뀔 내용만 대화에 보여 준다. `--dry-run` 을 빼고 다시 실행하면 문서에 반영된다.
