## 사용 case

### email 로그인과 Google 로그인 추가

Claude Code 는 option 없이 시작하고, 이어지는 질문에서 로그인 방식을 고릅니다. Codex 는 원하는 방식을 문장으로 줍니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-auth-implement --lang ko
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-auth-implement email·password 로그인과 Google OAuth 를 추가한다
```
</TabItem>
</Tabs>

**결과물**: 먼저 session, 탈퇴, password 정책 같은 인증 정책을 묻습니다. 답에 맞는 library 를 추천하고 인증 code 를 만듭니다. 보안 검토와 E2E 확인 결과도 함께 나옵니다.
