## 사용 case

### PR 을 만들기 전에

구현이 끝났다고 생각합니다. PR 을 만들기 전에 정말 끝났는지 확인합니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-verify-done
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-verify-done
```
</TabItem>
</Tabs>

**결과물**: test, build 같은 확인 명령을 다시 실행하고, 명령과 출력과 종료 코드를 근거로 보여 줍니다. 근거가 없는 완료 주장은 통과시키지 않습니다.
