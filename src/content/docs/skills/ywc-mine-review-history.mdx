## 사용 case

### 처음으로 리뷰 선호를 쌓을 때

리뷰 선호 file 이 아직 없습니다. 지난 반년치 PR 에서 반복된 지적부터 모읍니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-mine-review-history --since 2026-05-01 --limit 200 --dry-run
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-mine-review-history --since 2026-05-01 --limit 200 --dry-run
```
</TabItem>
</Tabs>

**결과물**: 반복된 지적이 결함 유형별로 묶여 나옵니다. 유형마다 이 저장소 전용 선호로 둘지, 여러 project 공통 결함 후보로 둘지 분류됩니다. `--dry-run` 이라 file 은 바꾸지 않습니다.
