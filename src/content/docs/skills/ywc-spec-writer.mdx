## 사용 case

### 끝낸 task 범위를 사양서에 반영

Phase 3 의 task 들을 병합했습니다. 그 사이에 바뀐 동작을 사양서에 반영합니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-spec-writer --from-tasks 000003-010..000003-050
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-spec-writer --from-tasks 000003-010..000003-050
```
</TabItem>
</Tabs>

**결과물**: 해당 task 들이 바꾼 부분만 반영됩니다. 대상은 `docs/specification/` 의 관련 섹션입니다.

### 병합한 PR 기준으로 갱신

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-spec-writer --from-prs 12 15
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-spec-writer --from-prs 12 15
```
</TabItem>
</Tabs>

**결과물**: 두 PR 의 변경을 합쳐 `docs/specification/` 을 갱신합니다.
