## 사용 case

### 기능 branch 를 마무리하며 PR

option 표 기능을 만든 branch 의 작업이 끝났습니다. 한국어로 PR 을 만듭니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-create-pr --lang ko --plan-doc docs/ywc-plans/20261028-option-table.md
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-create-pr --lang ko --plan-doc docs/ywc-plans/20261028-option-table.md
```
</TabItem>
</Tabs>

**결과물**: 보안 점검과 local CI 를 통과하면 push 하고 PR 을 엽니다. 설명에는 변경 요약, 계획 문서 인용, test 방법이 들어갑니다. 이어서 원격 CI 와 bot 리뷰 결과를 확인합니다.
