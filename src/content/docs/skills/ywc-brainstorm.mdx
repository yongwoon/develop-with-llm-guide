## 사용 case

### 만들 것은 떠올랐지만 범위가 흐릴 때

skill 사용법 guide 사이트를 만들고 싶지만, 누가 어떤 순서로 볼지는 아직 정하지 않았다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">

</TabItem>
<TabItem label="Codex">

**결과물**: 질문에 하나씩 답하면 목적·제약·성공 기준이 정리되고, 접근 방법 2~3개를 장단점과 함께 비교해 하나를 고른다. 합의한 설계는 `ywc-plan` 으로 넘길 수 있는 형태로 대화에 남는다. 대화가 길어지면 중간 초안을 `docs/ywc-plans/_brainstorm-<slug>.md` 에 둘 수 있다.

- 무엇을 만들지 이미 분명하다 → `ywc-plan`

- project 의 존재 이유를 기록하고 싶다 → `ywc-mission`
- 계획이 정해졌고 착수해도 되는지 판단하고 싶다 → `ywc-confidence-gate`
