## 사용 case

### ywc-plan 이 만든 spec 을 통과 상태로

`ywc-plan` 이 쓴 spec 에 지적이 남아 있습니다. task 로 나누기 전에 정리합니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-spec-ready --spec docs/ywc-plans/20261028-option-table.md
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-spec-ready --spec docs/ywc-plans/20261028-option-table.md
```
</TabItem>
</Tabs>

**결과물**: spec file 을 그 자리에서 고칩니다. 반복 기록은 `docs/ywc-plans/20261028-option-table.spec-ready-log.md` 에 쌓입니다. 끝나면 `ywc-task-generator` 로 넘어가라는 안내가 나옵니다.

### 목표 문장에서 바로 시작

<Tabs syncKey="tool">
<TabItem label="Claude Code">

</TabItem>
<TabItem label="Codex">
```text
$ywc-spec-ready skill 색인에 분류 filter 를 추가한다 --max-iterations 3
```
</TabItem>
</Tabs>

**결과물**: `docs/ywc-plans/<slug>.md` 에 spec 을 새로 만듭니다. 검토와 수정은 최대 3번까지 되풀이합니다.

## 쓰지 말아야 할 때

- 고치지 않고 한 번 검토만 받을 때 → `ywc-spec-validate`
- 다듬기 없이 계획만 세울 때 → `ywc-plan`
- spec 이 이미 통과했을 때 → `ywc-task-generator`
- 목표에서 구현까지 한 번에 맡길 때 → `ywc-agentic`
