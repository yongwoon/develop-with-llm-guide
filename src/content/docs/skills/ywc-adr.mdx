## 사용 case

### 정한 framework 를 결정으로 남기기

조사 끝에 Astro Starlight 를 쓰기로 정했고, 그 이유를 나중에 다시 찾아볼 수 있게 남긴다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-adr 정적 사이트 framework 로 Astro Starlight 를 채택한다. 한국어 검색과 MDX component 가 이유다
```
</TabItem>
<TabItem label="Codex">
Codex 에는 이 skill 이 없다. 결정 내용을 `docs/architecture/adr/` 에 직접 쓰거나, 기각한 접근이라면 `$ywc-mission` 으로 기록한다.
</TabItem>
</Tabs>

**결과물**: `docs/architecture/adr/` 에 번호가 붙은 ADR 파일이 새로 생긴다.

### 이전 결정을 대체하기

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-adr --supersedes ADR-0001 검색을 Pagefind 에서 외부 검색 service 로 바꾼다
```
</TabItem>
<TabItem label="Codex">
Codex 에는 이 skill 이 없다.
</TabItem>
</Tabs>

**결과물**: 새 ADR 이 생기고, `ADR-0001` 은 대체되었다고 표시된다.

## 쓰지 말아야 할 때

- 아직 결정을 내리지 못했다 → 먼저 `ywc-tech-research` 로 비교한다
- 구현 계획이나 spec 을 쓰고 싶다 → `ywc-plan`
- project 의 목적이나 기각한 접근을 기록하고 싶다 → `ywc-mission`
