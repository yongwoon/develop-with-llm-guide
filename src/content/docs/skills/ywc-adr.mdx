## 사용 case

### 정한 framework 를 결정으로 남기기

조사 끝에 Astro Starlight 를 쓰기로 정했습니다. 나중에 이유를 다시 찾아볼 수 있게 남깁니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-adr 정적 사이트 framework 로 Astro Starlight 를 채택한다. 한국어 검색과 MDX component 가 이유다
```
</TabItem>
<TabItem label="Codex">
Codex 에는 이 skill 이 없습니다. 결정 내용을 `docs/architecture/adr/` 에 직접 씁니다. 기각한 접근이라면 `$ywc-mission` 으로 기록합니다.
</TabItem>
</Tabs>

**결과물**: `docs/architecture/adr/` 에 번호가 붙은 ADR file 이 새로 생깁니다.

### 이전 결정을 대체하기

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-adr --supersedes ADR-0001 정적 사이트 framework 를 Astro Starlight 에서 VitePress 로 바꾼다
```
</TabItem>
<TabItem label="Codex">
Codex 에는 이 skill 이 없습니다. 새 결정을 `docs/architecture/adr/` 에 직접 씁니다. 이전 ADR 의 상태는 대체됨으로 고칩니다.
</TabItem>
</Tabs>

**결과물**: 새 ADR 이 생깁니다. `ADR-0001` 에는 대체되었다는 표시가 붙습니다.

### 더 이상 맞지 않는 결정을 폐기

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-adr --mode deprecate ADR-0002
```
</TabItem>
<TabItem label="Codex">
Codex 에는 이 skill 이 없습니다. 해당 ADR file 의 상태를 직접 폐기로 고칩니다.
</TabItem>
</Tabs>

**결과물**: `ADR-0002` 가 폐기 상태로 바뀝니다. file 은 지우지 않고 남깁니다.
