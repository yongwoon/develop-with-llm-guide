## 사용 case

### 정적 사이트 framework 를 고르기 전

guide 사이트를 만들 framework 를 아직 정하지 않았습니다. 후보 두 개를 같은 기준으로 비교하고, 결과를 저장소에 남깁니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-tech-research 한국어 검색이 되는 정적 문서 사이트 --compare "Astro Starlight,VitePress" --output docs/ywc-plans/static-site-framework-research.md
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-tech-research 한국어 검색이 되는 정적 문서 사이트 --compare "Astro Starlight,VitePress" --output docs/ywc-plans/static-site-framework-research.md
```
</TabItem>
</Tabs>

**결과물**: 보고서가 대화에 나오고 `docs/ywc-plans/static-site-framework-research.md` 에 저장됩니다. 보고서에는 후보별 비교표, 추천안, 이 project 에서 주의할 점, 출처가 들어갑니다. 계획 수립은 하지 않습니다.
