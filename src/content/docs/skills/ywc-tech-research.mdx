## 사용 case

### 정적 사이트 framework 를 고르기 전

guide 사이트를 어떤 framework 로 만들지 정하기 전에, 후보 두 개를 같은 기준으로 비교하고 결과를 저장소에 남긴다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-tech-research 한국어 검색이 되는 정적 문서 사이트 --compare "Astro Starlight,VitePress" --output docs/ywc-plans/static-site-framework-research.md
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-tech-research 한국어 검색이 되는 정적 문서 사이트 --compare "Astro Starlight,VitePress" --output docs/ywc-plans/static-site-framework-research.md
```
</TabItem>
</Tabs>

**결과물**: 후보별 비교표, 추천안, 이 project 에서 주의할 점, 참고 출처가 담긴 보고서가 대화에 나오고 `docs/ywc-plans/static-site-framework-research.md` 에 저장된다. 계획 수립까지는 하지 않는다.
