## 사용 case

### apply 전에 plan 결과 리뷰

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-infra-review --plan-file terraform-plan.txt
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-infra-review terraform-plan.txt 의 plan 결과
```
</TabItem>
</Tabs>

**결과물**: IAM 권한, network 노출, state lock, 비용, 신뢰성 관점의 지적이 심각도별로 나옵니다. 지적마다 자원 위치와 고치는 방향이 붙습니다.
