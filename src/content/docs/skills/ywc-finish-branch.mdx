## 사용 case

### 혼자 쓰는 저장소에서 바로 병합

task 하나의 구현과 검증이 끝났습니다. PR 없이 base branch 에 병합하고 완료 처리합니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-finish-branch --mode local-merge --branch feature/000004-010-ui-flow-pages-10-17 --base-branch content/initial --task-name 000004-010-ui-flow-pages-10-17
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-finish-branch --mode local-merge --branch feature/000004-010-ui-flow-pages-10-17 --base-branch content/initial --task-name 000004-010-ui-flow-pages-10-17
```
</TabItem>
</Tabs>

**결과물**: feature branch 가 base branch 에 병합되고 push 됩니다. task 디렉터리는 `tasks/completed/` 로 옮겨지고 완료 commit 이 남습니다. local feature branch 는 지워집니다.

## 쓰지 말아야 할 때

- branch 를 새로 만들 때 → git 명령이나 executor
- PR 만 만들고 병합하지 않을 때 → `ywc-create-pr`
- 커밋만 할 때 → `ywc-commit`
- 열린 PR 의 리뷰 코멘트를 처리할 때 → `ywc-handle-pr-reviews`
