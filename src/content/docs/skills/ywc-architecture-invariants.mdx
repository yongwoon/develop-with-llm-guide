## 사용 case

### 경계 규약 초안 만들기

component 가 content 를 import 하지 못하게 하는 등 경계를 file 로 남기고 싶습니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-architecture-invariants --mode draft
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-architecture-invariants --mode draft --root . --output architecture-invariants.yaml
```
</TabItem>
</Tabs>

**결과물**: `architecture-invariants.yaml` 에 component 목록과 금지 의존 관계 초안이 생깁니다.

### branch 의 변경이 규약을 지키는지

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-architecture-invariants --mode audit --git-range main..HEAD
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-architecture-invariants --mode audit --root . --changed-path src/components
```
</TabItem>
</Tabs>

Codex 에는 --git-range 가 없어 점검할 경로를 --changed-path 로 줍니다.

**결과물**: 변경된 file 이 어느 component 에 속하는지와, 금지된 의존을 만든 곳이 있는지 보고합니다.
