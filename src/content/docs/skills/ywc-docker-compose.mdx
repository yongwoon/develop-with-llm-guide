## 사용 case

### Docker 환경이 없는 project 에 처음 만들기

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-docker-compose --mode create --app-name sample-api
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-docker-compose --mode create
```
</TabItem>
</Tabs>

**결과물**: compose file, 개발용 `Dockerfile.local`, 운영용 `Dockerfile` 이 생깁니다. 여러 git worktree 에서 동시에 띄울 수 있는 구성입니다.

### base image 만 최신화

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-docker-compose --scope images
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-docker-compose --scope images
```
</TabItem>
</Tabs>

**결과물**: base image 와 service image 의 tag 가 현재 LTS·안정 버전으로 바뀝니다. package 와 구성은 건드리지 않습니다.
