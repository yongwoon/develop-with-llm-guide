## 사용 case

### 기존 skill 들이 규칙을 지키는지 점검

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-skill-author 모든 ywc skill 이 현재 규칙을 지키는지 점검해 줘
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-skill-author --mode audit --skill-root skills/
```
</TabItem>
</Tabs>

**결과물**: skill 마다 규칙 위반 항목과 고칠 방향이 나옵니다. audit 는 file 을 바꾸지 않습니다.
