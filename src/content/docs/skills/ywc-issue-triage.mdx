## 사용 case

### 쌓인 issue 를 먼저 훑어보기

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-issue-triage --dry-run
```
</TabItem>
<TabItem label="Codex">
Codex 에는 이 skill 이 없습니다. gh CLI 로 issue 목록을 보며 label 을 직접 정리합니다.
</TabItem>
</Tabs>

**결과물**: issue 마다 분류(bug, enhancement)와 상태(needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix) 추천이 나옵니다. 실행할 gh 명령도 함께 보여 주지만 적용하지는 않습니다.
