## 사용 case

### 서로 독립인 page 작성 task 를 동시에

Phase 4 의 흐름 page task 들은 서로 file 이 겹치지 않습니다. 한꺼번에 돌리고 PR 하나로 받습니다.

<Tabs syncKey="tool">
<TabItem label="Claude Code">
```text
/ywc-parallel-executor 000004-010..000004-030 --aggregate-pr --review
```
</TabItem>
<TabItem label="Codex">
```text
$ywc-parallel-executor 000004-010..000004-030 --aggregate-pr --review
```
</TabItem>
</Tabs>

**결과물**: task 마다 worktree 가 생겨 동시에 구현됩니다. 결과는 `aggregate/` branch 하나에 모이고, PR 하나가 CI 와 자동 리뷰를 거쳐 병합됩니다. 끝난 worktree 는 정리됩니다.

## 쓰지 말아야 할 때

- task 가 앞 task 결과에 기대어 차례로 진행돼야 할 때 → `ywc-sequential-executor`
- 순차·병렬을 정하지 않고 맡길 때 → `ywc-task-executor`
- task 그래프 없이 일을 나눠 맡길 때 → `ywc-team-assemble`
- 목표 문장 하나로 계획부터 맡길 때 → `ywc-agentic`
