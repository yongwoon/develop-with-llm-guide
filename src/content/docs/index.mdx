ywc skill 과 agent 를 어떤 상황에서, 어떤 option 으로 쓰는지 정리한 guidebook 입니다.

## 이 guide 사용법

- **상황에서 출발**: 아래 흐름 목록에서 지금 상황을 고릅니다. 흐름 page 에서 skill 이름을 누르면 그 skill 의 option 표로 갑니다.
- **skill 이름으로 출발**: [Skill 색인](/develop-with-llm-guide/skills/) 에서 skill 을 고르거나, 위쪽 검색(⌘K / Ctrl+K)에 skill 이름이나 option 이름을 넣습니다.
- **처음 설치할 때**: [설치](/develop-with-llm-guide/getting-started/install/) 와 [두 도구의 차이](/develop-with-llm-guide/getting-started/tool-differences/) 를 먼저 봅니다.
- **어느 skill 을 쓸지 모를 때**: [헷갈리기 쉬운 skill](/develop-with-llm-guide/guides/choosing-skills/) 비교표나 [자주 쓰는 명령](/develop-with-llm-guide/guides/cheat-sheet/) 을 봅니다.

## 사용 안내

- [자주 쓰는 명령](/develop-with-llm-guide/guides/cheat-sheet/): 상황별 대표 명령을 한 page 에 모았습니다.
- [헷갈리기 쉬운 skill](/develop-with-llm-guide/guides/choosing-skills/): 비슷한 skill 을 비교합니다.
- [말로 부르기](/develop-with-llm-guide/guides/natural-language/): skill 이름 없이 요청으로 시작하는 방법입니다.
- [공통 option](/develop-with-llm-guide/guides/common-options/): 여러 skill 에 같은 뜻으로 있는 option 입니다.
- [설정](/develop-with-llm-guide/guides/configuration/): 언어, base branch 같은 기본값을 정하는 곳과 우선순위입니다.
- [산출물 지도](/develop-with-llm-guide/guides/outputs-map/): 어떤 file 을 어느 skill 이 만드는지 봅니다.
- [문제 해결](/develop-with-llm-guide/guides/troubleshooting/): 막혔을 때 확인할 것입니다.
- [실제 case: 이 사이트](/develop-with-llm-guide/guides/case-this-site/): 이 사이트를 ywc skill 로 만든 과정입니다.
