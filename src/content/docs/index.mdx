## 이 guide 사용법

- **상황에서 출발**: 아래 흐름 목록에서 지금 상황을 고릅니다. 흐름 page 에서 skill 이름을 누르면 그 skill 의 option 표로 갑니다.
- **skill 이름으로 출발**: [Skill 색인](/develop-with-llm-guide/skills/) 에서 skill 을 고르거나, 위쪽 검색(⌘K / Ctrl+K)에 skill 이름이나 option 이름을 넣습니다.
- **처음 설치할 때**: [설치](/develop-with-llm-guide/getting-started/install/) 와 [두 도구의 차이](/develop-with-llm-guide/getting-started/tool-differences/) 를 먼저 봅니다.
